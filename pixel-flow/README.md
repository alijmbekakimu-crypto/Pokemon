# Pixel Flow — студия

Здесь делаются Shorts для канала **Pixel Flow**. Вся графика, шрифт, звуки и музыка
генерируются кодом (Python + numpy + ffmpeg), поэтому всё оригинальное — никаких чужих ассетов.

## Серии

| Папка | Серия | Статус |
|---|---|---|
| `good-boy-exe/` | **GOOD BOY.exe** — девочка Мира и робот-пёс Болт | Shorts эп. 1 + фильм 20:26 |

## Как отрендерить

```bash
cd pixel-flow/good-boy-exe
python3 ep01.py --stills   # только раскадровка (1 сек)
python3 ep01.py            # полное видео out/ep01.mp4 (~20 сек)
python3 sheet.py           # лист персонажей и фон
```

Фильм (16:9, 1920×1080, 20 мин 26 сек):

```bash
cd pixel-flow/good-boy-exe/film
python3 render.py stills       # раскадровка всех глав (секунды)
python3 render.py all -j 4     # весь фильм -> out/film/GOOD_BOY_EXE_film.mp4 (~10 мин)
python3 thumb.py               # обложки 1280x720
```

Нужно: `python3`, `numpy`, `Pillow`, `ffmpeg`.
Готовые mp4 в git не кладутся (слишком большие) — их всегда можно перерендерить.

## Устройство

- `engine.py` — пиксельный движок: экран 180×320 «толстых пикселей» → 1080×1920, камера с зумом,
  свой шрифт 5×7, дождь, виньетка, вспышка, глитч.
- `cast.py` — персонажи (спрайты нарисованы попиксельно): Болт, Мира, папа, ящик, мячик.
- `sets.py` — локации (двор ночью: луна, дом, забор, могила).
- `audio.py` — синтезатор: дождь, гром, шаги, писки робота, пианино и пэд.
- `epNN.py` — одна серия: сюжет по времени, камера, титры, звук.
- `SCRIPTS.md` — сценарии серий 1–5.
- `film/` — полнометражный фильм: `script.py` (8 глав, 156+ сцен), `tl.py` (режиссёрский движок: камера,
  актёры, титры, эффекты), `sets16.py` (10 локаций), `props.py`, `score.py` (музыка 7 настроений + 40 звуков),
  `render.py`, `thumb.py`, `YOUTUBE.md` (название, описание с таймкодами, теги, закреп).

Новая серия = скопировать `ep01.py` в `ep02.py` и поменять функции состояния, камеру, `CAPS` и `soundtrack`.
